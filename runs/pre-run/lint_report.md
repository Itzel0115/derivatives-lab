## 明細

### L-01 術語表排序

`AGENTS.md` §8.3 規定依英文字母排序。以下相鄰兩列順序顛倒（前者應排在後者之後）：

- Black-Scholes formula ／ automatic call
- simplified equity-linked note ／ estimated value
- historical volatility ／ hidden costs
- pricing supplement ／ physical delivery
- put option ／ principal protection
- slice ／ sell put
- Surface SVI ／ static arbitrage
- unsecured creditor ／ unit of trading

原因是 ingest 時把新條目插在某個既有條目之前，沒有重新檢查順序。

### L-08 程式檢查不到的部分

1. **沒有短引的出處。** `[範例]` 與 `[推導]` 行只有頁碼、沒有短引，程式無法核對頁碼。S6 ingest 時就因此漏過一個錯誤頁碼，靠人工才發現。

3. **`[範例]` 的數字。** 除了 S8 另外用程式比對過 15 個數字之外，其餘都是對照來源手抄的。
4. **中文改寫是否忠於原意。** 沒有任何獨立複核。這是 C4-4（白話化失真）要抓的問題，但在 wiki 這一層沒有對應的檢查。

另外，公式卡 F03–F05、F10–F16 是對照 PDF 原圖人工抄錄的 LaTeX；F06–F09、F17 是推導。兩者目前只經過暫存腳本的數值預檢，正式驗證要等 C3。

### L-09 raw 原檔的換行

這台機器的 git 會提示「LF will be replaced by CRLF」。目前 repo 中 `raw/s6-…html`、`raw/s7-…html` 的內容與下載時一致，但在啟用換行轉換的 Windows 環境 clone 時，工作目錄中的檔案可能被轉成 CRLF，SHA-256 就會和 MANIFEST 對不上。加一個 `.gitattributes` 把 `raw/` 設為不轉換可以避免。
